# Upload page cosmetic changes

Branch: `upload-status-cosmetic-ui-changes`

## Move Edit Assignment button under the assignment title
The Edit Assignment button now sits directly beneath the assignment name in the exam header instead of in the top-right corner.

## Show assignment status badge beside the title
The workflow status badge (for example "In review") now appears next to the assignment name rather than in the right-hand action row.

## Move Open grading button above Students without an exam on upload page
On the Upload page, Open grading is now a large full-width button above the "Students without an exam" card, and is hidden from that page's header.

## Add subway-style workflow map with smaller step buttons in the exam header
The header now shows a subway-style map of all five workflow stops (finished, current and not-yet-reached) in the top right, with smaller, centered Move back and forward buttons beneath it.

## Upload Status: segmented bar with no-show and excused sections, plus counts
The card is renamed "Upload Status" and its progress bar is split into teal (has an exam), red (no-show), yellow (excused) and grey (unmatched) sections, with new No-show and Excused counts below.
